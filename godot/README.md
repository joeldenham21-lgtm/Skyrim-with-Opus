# RADIUS (Godot)

The Godot 4.5 remake of RADIUS, a first-person survival horror in the Pechorsk Restricted Zone in the spirit of
*Into the Radius 2*. Open this folder in Godot 4.5 (Forward+) and press Play, or run an exported build from `builds/`.

- Design bible: `../radius/DESIGN.md` · gear and progression: `../radius/GEAR.md` · the yardstick: `../radius/REFERENCE.md`
- Engine plan and contracts: `GODOT.md`
- Headless screenshots for verification: `tools/shot.sh tools/scenarios/<name>.gd` (Xvfb + Mesa software Vulkan)
- Generated assets: `tools/gen_textures.py` (PBR texture sets), `tools/gen_audio.py` (sound and music)

Controls: WASD move · Shift sprint · C crouch · Space jump · LMB fire · RMB aim · R reload · T load rounds · F torch ·
G probe · E interact · 1–4 weapons · 5 detector · B fire mode · L weapon light · V melee · X grenade · N binoculars ·
6–9 quick slots · Tab watch · I inventory · M map · Esc pause · F3 stats. Touch controls appear on phones and tablets.
